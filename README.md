Proyecto: Domina Excel con IA
Universidad EAN – EanX
Descripción del proyecto
Este proyecto consiste en analizar las ventas mensuales de una empresa utilizando Excel y herramientas de inteligencia artificial.
Objetivo
Identificar el mes con mayores ventas, analizar el comportamiento de las ventas durante el año y realizar una proyección para el siguiente mes.
Herramientas utilizadas
- Microsoft Excel
- ChatGPT como herramienta de inteligencia artificial complementaria
- Fórmulas y gráficos de Excel
Desarrollo
Se utilizaron datos simulados de ventas de 12 meses. Con Excel se realizaron cálculos de ventas totales, promedios y pronósticos.
Con ayuda de ChatGPT se organizaron los datos, se seleccionaron las fórmulas y se interpretaron los resultados.
Resultados
El mes con mayores ventas fue diciembre, con $21.300.000. Los resultados muestran una tendencia general de crecimiento durante el año.
Conclusión
Este proyecto permitió comprender cómo Excel y la inteligencia artificial pueden trabajar juntos para facilitar el análisis de información y apoyar la toma de decisiones.
